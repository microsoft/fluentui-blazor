# Profile menu

The `FluentProfileMenu` component displays a user avatar that opens a popover containing profile details and account actions.

Use `FullName`, `EMail`, `Image`, `Initials`, and `Status` for the default presentation. The header, body, footer, and content surrounding the trigger avatar can all be replaced with templates.
